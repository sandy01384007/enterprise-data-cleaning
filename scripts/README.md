# 企业AI知识库 · 数据清洗自动化脚本工具包

适用：晟泰智慧能源知识库建设（设计、财务、人事、行政、投标、造价等）及通用企业场景

## 脚本列表

| 脚本 | 功能 | 使用场景 |
|------|------|----------|
| 01_file_inventory.py | 扫描文件夹，生成文件盘点表（Excel） | 第一步盘点 |
| 02_batch_rename.py | 按命名规范批量重命名 | 标准化文件名 |
| 03_desensitize_text.py | 文本脱敏（身份证、手机、金额、邮箱等） | 敏感信息处理 |
| 04_pdf_to_text.py | 批量PDF转纯文本 | 格式转换 |
| 05_generate_metadata_template.py | 生成元数据填写模板Excel | 元数据补全 |

## 使用前准备

```bash
pip install pypdf python-docx openpyxl pandas
```

建议在测试文件夹先跑，确认无误后再处理正式数据。

## 注意事项

- 脱敏脚本基于正则，无法识别所有上下文敏感信息，**必须人工复核**。
- 财务、人事、真实报价等高度敏感数据，建议人工处理为主，脚本仅辅助。
- 运行前请备份原始文件。
